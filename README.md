# America’s Miracle Painting LLC

Responsive static website. Includes all website images, CSS, and JavaScript.

## GitHub
Extract this ZIP and upload the contents to your repository root.

## Vercel
Import the repository. Framework preset: Other. No build command. Output directory: .

## GitHub Pages
In Settings > Pages, select Deploy from a branch, main, / (root).

## Local preview
Run `python -m http.server 8000` in this folder and open http://localhost:8000.

Photos are illustrative design inspiration, not client project documentation. Fonts load from Google Fonts, with local fallbacks.
